## Módulo Remitos (Septiembre)

### ¿Qué se hizo?
Desarrollamos el sistema completo de remitos digitales para reemplazar el manejo manual.

### Funcionalidades incluidas

**1. Gestión de productos mejorada**
- Sistema de rankings para priorizar productos más vendidos
- Podés marcar productos como favoritos para que aparezcan primero
- Fotos de productos para identificarlos visualmente

**2. Proceso de remitos optimizado**
- Flujo de 2 pasos: primero seleccionás productos, después confirmás los datos del cliente
- Estados claros: Pendiente → En Revisión (con foto del remito firmado) → Completado
- Posibilidad de anular un remito en cualquier momento

**3. Fotos de remitos**
- El ingeniero puede sacar una foto del remito firmado desde el celular
- La foto queda adjunta al remito para verificación

### Beneficio
Reducción de errores, trazabilidad completa y proceso más rápido.

## Stock y Compras (Septiembre)

### ¿Qué se hizo?
Mejoras en la gestión de inventario y compras a proveedores.

### Funcionalidades incluidas

**1. Stock inteligente**
- El sistema maneja automáticamente diferentes presentaciones de productos (pack, kilo, unidad)
- Conversión automática entre unidades (ej: 50 packs = 1000 kilos)
- Sistema FIFO (primero en entrar, primero en salir) para control de lotes

**2. Compras a proveedores**
- Compras pueden enviarse a múltiples destinos/depósitos
- Búsqueda rápida de productos con autocompletado
- Vista clara de distribución por destino

**3. Reestructuración de productos**
- Productos simplificados: solo nombre, código y estado
- Presentaciones como unidades de medida independientes

### Beneficio
Mejor control de stock, menos errores en compras y distribución.
